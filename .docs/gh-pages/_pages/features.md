# Features and Components

## Features

- Hyprland 0.55+ configured in Lua.
- `dwindle` layout, gaps, rounded corners, blur, shadows and animations.
- Workspaces 1 to 9, keyboard navigation and resize mode for floating windows.
- Window grouping into tabs and global switching with `snappy-switcher`.
- Top Waybar with workspaces, active window, MPRIS, audio, network, CPU, memory, date/time, keyboard layout, tray, recording and power menu.
- Side Waybar sysinfo with machine, CPU/GPU, memory, storage, processes, network and shortcut reminder.
- Quickshell right sidebar with notifications, calendar, weather, volume, network, CPU/RAM/GPU, keyboard layout and power profiles.
- Rofi as launcher, theme selector, power menu, calculator and clipboard picker.
- Clipboard history with `cliphist`, `wl-clipboard` and Rofi integration.
- Screenshots with `hyprshot` and region editing with `satty`.
- Screen recording with `gpu-screen-recorder`, pause/resume and status in Waybar.
- Locking with `hyprlock`, blurred wallpaper generated by `magick`, idle via `hypridle` and logout screen with `wlogout`.
- Full theme system with 11 thematic variations inspired by *Blasphemous* and *Blasphemous II*.
- Wofi as an alternative launcher to Rofi.
- `blasphemous-desktop/sh/` — shared shell library with logging, locale, notification, JSON, string and path handling functions.
- Audio via PipeWire/WirePlumber, controlled with `wpctl`, `pamixer` and `pwvucontrol`.
- Support for multimedia shortcuts, brightness, color picker, emoji picker and default browser.
- Kitty and Foot terminals with JetBrainsMono Nerd Font, Font Awesome and themes per active theme.
- Superfile (`spf`) as the default file manager, opened in Kitty with `Super + Space` and integrated with the theme system.
- Yazi with custom flavors (flexoki-dark, flexoki-fragment-of-guilt, repose-of-the-silent-one).
- Wayland settings for Firefox, Electron, SDL2, Java, LibreOffice and cursor.
- Dark GTK theme with Graphite-teal-Dark and Mint-Y-Teal icons applied by the installer.
- Bilingual support (Portuguese/English) in cheatsheets, menus, sidebar and scripts.
